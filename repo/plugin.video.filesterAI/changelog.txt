1.2.0 (2026-10-27)
- File thumbnails: has_thumbnail:true + null URL now resolves via GET /file/{id}, with best-effort /t/{uuid} fallback (404s never retried). TTL-bounded cache (15 min), batch of 20 per listing in the background thread, rest on demand.
- Folders ALWAYS sort A-Z (Z-A only when explicitly picked) — Largest/Newest no longer shuffle navigation. Name keys fall back name → original_name → id.
- API layer now hosts cycle helpers (move_exclusions), thumbnail semaphore (max 4 concurrent), and all thumbnail caching semantics per gotcha #8.
1.1.0 (2026-10-27)
- Folder destination picker now excludes the folder AND all its descendants (server accepts cycles — client must not offer them).
- Sorting is always global: fetch all pages, sort, then paginate. Per-page-sort option removed.
- Retry policy: transient/5xx retried max twice with jittered backoff; 429 never retried inline. SSL fallback on every HTTPS endpoint (incl. public/view and folder pages) with log warning, never cached.
- Folder thumbnails: session cache (definitive negatives cached, transient failures never cached), prefetched in a background thread without blocking listings, throttled refresh (~5/min, current-path check).
- Kodi gotchas: no more addSortMethod (client-side sort wins), IsPlayable only on video files, xbmcvfs handles always closed, Dialog().input instead of deprecated Keyboard.
- Search matches name AND original_name, warns (no silent truncation) when over the 200-item display cap.
1.0.0 (2026-10-27)
- Initial release.
- Browse folders + files, search, client-side sort (newest/oldest/A-Z/Z-A/largest/smallest).
- One-click video playback via slug -> public/view resolver with Kodi User-Agent suffix.
- File details dialog (size/date/views/downloads/slug/streamable).
- Create folder, delete file/folder (with confirm), move file/folder (folder picker), set folder thumbnail (5MB JPG/PNG/GIF/WebP check).
- Folder thumbnails via public page og:image; file thumbs wherever the API returns them.
- Pagination with dedupe (safe against /folder/id/files page bug), optional fetch-all-then-sort.
- CDN cache-busting (_t + no-cache), 429 rate-limit notice, expired-cert auto-retry (u1.filester.me Oct 2026).
